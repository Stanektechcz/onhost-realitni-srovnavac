# ONHOST Security Policy

Zranitelnosti nepublikujte ve veřejném GitHub Issue. Použijte soukromý GitHub Security Advisory / private vulnerability reporting, pokud je dostupný, nebo si vyžádejte bezpečný soukromý kontakt od oprávněného maintaineru.

Projekt může být koncept, prototype nebo staging; bezpečnostní podporu verzí a pravidla zveřejnění musí určit vlastník. Neprovádějte neautorizované scany ani zásahy do zákaznických serverů. V reportu uvádějte commit, dopad a minimální anonymizované kroky, nikoli osobní data či secrets.
