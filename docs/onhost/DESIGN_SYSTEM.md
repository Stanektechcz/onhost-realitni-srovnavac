# UI, design a branding — ONHOST Reality

**Návrh barev:** #12001E,#3C096C,#F72585

ONHOST má schválený firemní Brand V2, jednotlivé produkty však mohou mít odlišnou identitu; uvedená paleta musí být potvrzena proti skutečným CSS tokenům nebo vlastníkem.

1. Priorita: čitelná typografie, jasný hlavní úkol a mobilní rozložení.
2. Loading, empty, pending, denied, failure a success stavy jsou povinné.
3. A11y: klávesnice, fokus, kontrast, reduced-motion, smysluplné chyby formulářů.
4. Citlivé nebo destruktivní akce musí být odlišitelné od běžné navigace.
5. Barevný štítek nikdy nenahrazuje textovou informaci o stavu.
