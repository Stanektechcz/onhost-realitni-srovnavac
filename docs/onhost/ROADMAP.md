# Roadmapa — ONHOST Reality

**Nejbližší milník:** Dokončit český MVP a moderaci

| Vlna | Výsledek | Kontrola |
|---|---|---|
| Discovery | cíloví uživatelé, data, vazby a rizika | potvrzení vlastníkem |
| Foundation | setup, politika oprávnění, první testy | negativní auth test |
| MVP | minimální kompletní uživatelský scénář | evidence v CI a stagingu |
| Integrace | contract tests a recoverable workflows | provider sandbox |
| Go-live | monitoring, obnova, právní podklady a finance | owner go/no-go |

**Integrace k ověření:** ONHOST ID/Wallet za feature flags, Elaris Mate
