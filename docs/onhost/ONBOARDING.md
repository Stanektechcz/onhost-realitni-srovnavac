# Vývojářský onboarding — první den

1. Získat schválený GitHub přístup a přečíst repo README, AGENTS.md (pokud existuje), Product a Architecture.
2. Ověřit manifesty a lokálně spustit jen izolované prostředí.
3. Zjistit, které funkce existují, které mají testy, které jsou zatím návrh.
4. Projít jednu doménovou entitu, jedno API nebo UI flow a jeden failure test.
5. Založit issue s akceptačními kritérii a izolovanou větev.
6. Odevzdat draft PR s evidence a handoff.

**Lokální postup:** ```bash
composer install
npm install
php artisan test
npm run build
```
