# Přispívání do ONHOST Reality

1. Přečíst README a [vývojové centrum](docs/onhost/README.md).
2. Založit issue s cílem, akceptačními kritérii a závislostmi.
3. Pracovat na vlastní větvi, přidat testy a aktualizovat dokumentaci.
4. Odevzdat draft PR s provedenými příkazy a výsledky.
5. U rizikových operací počkat na schválení vlastníka.
